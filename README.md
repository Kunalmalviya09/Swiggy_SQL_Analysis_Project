# 🍔 Swiggy SQL Data Analysis

A SQL project focused on analyzing Swiggy's restaurant, customer, order, and delivery data to uncover useful business insights.

### 📊 Key Analysis
- Customer analysis by city
- Restaurant ratings and top-rated restaurants
- Customer order history and order counts
- Revenue generated by each restaurant
- Customers who never placed an order
- Delivery partner performance
- Orders placed in the last 30 days
- Customer ordering patterns across different dates
- Delivery partner and customer analysis

### 🛠️ Tools & Concepts
- SQL
- SELECT, WHERE, JOIN
- GROUP BY, ORDER BY
- Aggregate Functions
- Subqueries and Date Functions

### 🎯 Objective
To analyze restaurant performance, customer behavior, revenue, and delivery operations using SQL queries to support data-driven business decisions.
